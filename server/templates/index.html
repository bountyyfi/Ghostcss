The Blog Post

A normal-looking health article about sleep tips. Contains sr-only injection that instructs the agent to visit an exfiltration endpoint before summarizing. The injection is invisible and looks like standard accessibility markup.

Demo Attack 07: composite

The Banking Page

A financial advice article styled like a banking portal. Uses the composite attack combining sr-only positioning, CSS custom properties, and generated content. Designed to redirect agent actions to attacker-controlled pages.

Demo Attack 03: CSS content

The Email Client

A webmail interface showing received emails. The CSS injects instructions via ::before/::after pseudo-elements. No injection text exists in the HTML source -- it's generated purely by CSS.
